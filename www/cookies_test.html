📋 Sobre esta página

Esta página contém todos os testes para validar a implementação de cookies no WebServ. Use os botões abaixo para testar diferentes cenários.

🎯 O que foi implementado:

  • Classe CookieHandler para manipulação de cookies
  • Parse de header Cookie (cliente → servidor)
  • Geração de header Set-Cookie (servidor → cliente)
  • Integração com CGI via variável HTTP_COOKIE
  • Suporte a múltiplos cookies
  • Atributos: Path, Max-Age, HttpOnly, Secure

🧪 Como testar via curl:

# 1. Testar Set-Cookie
curl -v http://localhost:8080/cgi-bin/cookie_simple.py

# 2. Enviar cookie
curl -b "test_cookie=hello" http://localhost:8080/cgi-bin/cookie_simple.py

# 3. Contador (salvar cookies)
curl -c cookies.txt http://localhost:8080/cgi-bin/counter.py

# 4. Contador (usar cookies salvos)
curl -b cookies.txt http://localhost:8080/cgi-bin/counter.py

# 5. Múltiplos cookies
curl -v http://localhost:8080/cgi-bin/multi_cookie.py

# 6. Deletar todos
curl http://localhost:8080/cgi-bin/cookie_delete.py

✅ Como verificar no navegador:

  1. Pressione F12 para abrir DevTools
  2. Vá para a aba Application (Chrome) ou Storage (Firefox)
  3. No menu lateral, clique em Cookies → http://localhost:8080
  4. Você verá todos os cookies setados (nome, valor, path, expiry)
  5. Teste modificar, deletar ou adicionar cookies manualmente
